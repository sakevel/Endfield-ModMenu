# 模组菜单 (Mod Menu)

为《明日方舟：终末地》提供原生风格的游戏内模组管理与配置菜单。在游戏 ESC 主菜单中添加快捷入口，支持在游戏内直接查看模组详情并调整配置。

## 功能特性

- **原生界面风格**：与游戏 UI 视觉和交互逻辑无缝统一。
- **配置即时生效**：支持开关、滑块、下拉列表和输入框等设置项，修改后即时保存并支持热重载。
- **扩展配置支持**：支持其他模组注册自定义的高级配置页面（如可视化拖拽排版界面）。
- **个性化设置**：支持自定义菜单背景不透明度、列表密度等外观细节。

## 使用方法

1. 安装 ZML 及本模组后正常启动游戏。
2. 按 `ESC` 打开游戏主菜单，点击右侧的「模组菜单」按钮。
3. 在列表中点击任意模组即可查看详情或修改参数。
